# Elakkiya Durai — Futuristic Portfolio

A static portfolio template with a dark technical design, responsive navigation, animated scroll reveals, and a Three.js wireframe hero. It uses plain HTML/CSS/JavaScript, so no build command or paid service is required.

## Files

- `index.html` — portfolio content and project links
- `style.css` — layout, colors, responsive styles, and CSS fallback visuals
- `script.js` — mobile navigation, reveal animations, and Three.js scene

## Publish free with GitHub Pages

1. Sign in at https://github.com/ and create a **new public repository** named `elakkiya-portfolio`.
2. On the repository page, select **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` from this folder. Upload `README.md` too if you want.
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait for the Pages deployment to finish. The public URL will usually be `https://YOUR-GITHUB-USERNAME.github.io/elakkiya-portfolio/`.
9. Open the URL in a private/incognito window and test navigation, project links, and mobile layout.

GitHub Pages availability and settings can change; follow the current instructions shown in your repository's Settings → Pages screen. A public repository means the source code is public. The published website itself is public as well.

## Customize text

Open `index.html` in a plain-text editor (Notepad or VS Code) and search for the text you want to change. Keep the section IDs (`home`, `about`, `skills`, `projects`, `education`, `contact`) intact unless you also update their navigation links.
